# 🌍 COUNTRY-APP 

**Test Angular application for displaying and managing country information.**

### 🚀 Technologies
- [x] Angular 21+
- [x] Angular Material
- [x] RxJS
- [x] JSON Server (mock API)
- [x] TypeScript
- [x] biome

### 📋 Prerequisites
- [x] [Node.js v24+](https://nodejs.org/) 
- [x] [PNPM v10.26+](https://pnpm.io/) 
- [x] [Git  v2.47+](https://git-scm.com/)

### ⚡ Quick Start 
> Clone the repository
```bash
git clone https://github.com/DrabantBY/country-app.git
```
```bash
cd country-app
```
> Install dependencies
```
pnpm install
```
> Run data server at localhost:3000 (separate terminal)
```
pnpm run server
```
> Run application at localhost:4200 (separate terminal)
```
pnpm start
```
