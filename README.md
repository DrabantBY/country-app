# country-app
angular test project


### install:
- [x] node (v24.4.1)
- [x] package manager pnpm (v10.26.0)
- [x] git (v2.47.1)

### clone app:
- [x] run console
- [x] enter ```git clone https://github.com/DrabantBY/country-app.git```
- [x] open app in your ide
- [x] run ide terminal
- [x] go to app folder
- [x] install deps ```pnpm install```
- [x] run server ```pnpm run server```
- [x] open new terminal
- [x] run app ```pnpm start```
- [x] go to localhost:4200
